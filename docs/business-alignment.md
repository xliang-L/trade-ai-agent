# 外贸 AI Agent 第一版业务对齐清单

本清单用于与销售、采购、主管和账号负责人确认第一版配置。依据需求规格 V1.2 第十二、十四、十七、二十节整理。业务未知项尚未确认；以下开发默认值仅用于模拟演示，不代表正式业务授权。

## MVP 原文要求

第一阶段包括客户 CRM、供应商与内外库存、历史询单、WhatsApp AI 接待、基础匹配、人工核验工作台、48 小时有效报价及利润规则。AI 收集需求并给出建议，工作人员核验库存真实性、可售数量和底价；购买、锁货、付款、开单、发票等必须人工接管。

因此第一版最终应接入 WhatsApp。当前先实现内部流程和模拟入口，是开发顺序，不是删减该需求。AI 是否可自动发普通回复或正式报价、使用哪种 WhatsApp 接入方式，原文没有给出可执行配置，需要确认。

## 可先开发的默认方案

- 公司共享货源与已发布知识库；客户按负责人隔离。客户资料是否全员共享仍待确认。
- 先用模拟客户、库存与测试账号，不导入真实数据、不对外发送。
- 演示币种 USD，金额按美分；演示单位加价 USD 2、最低利润 USD 1。这些只是测试数字。
- 默认报价窗口 48 小时，但不超过核验和货源有效期。
- 正式配置未确认前，AI 仅生成草稿；不会自动核验、批准报价、锁货、收款或开单。
- 当前本机 API 固定测试销售身份。正式登录、多角色工作台和真实渠道尚未交付。

## 推荐收集的材料

1. 脱敏客户表、供应商货源表、内部库存表各一份，附原列名与更新时间说明。
2. 5–10 个典型询价案例：有货、无货、压价、版本不符、购买意向、投诉等，去掉真实客户联系方式。
3. 一份现行报价样例与公司 SOP；没有时由销售先填写规则表，系统再形成可审核配置。
4. WhatsApp 账号类型与服务商信息。密钥由后续安全配置流程注入，不填写到这份文档或 Git。

# ADR 0001 业务系统与运行时分离

日期：2026-10-07。状态：采纳架构边界；具体 runtime 选型待验证。

需求涉及多业务员共享货源、客户长期记忆、人工核验、有效报价和未来 ERP 同步。模型对话或 harness 状态不能承担这些业务事实。

决定：用模块化单体承载业务规则与数据库，用独立 worker 执行持久任务；AgentRuntime 接口隔离 harness，优先验证 Codex app-server。所有外部发送经业务网关，库存核验、特殊报价批准与最终成交由授权人员执行。

收益是数据和风控独立于模型升级，第二三版沿事件和模块扩展。代价是必须实现工具授权、可靠任务与发送幂等；Codex 无法代替这些部分。若 PoC 质量、成本或隔离条件不满足，替换运行时并记录新 ADR，不迁移核心 CRM 数据。

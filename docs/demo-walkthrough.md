# 贸联工作台演示说明

这是一份供业务讨论和老板现场演示使用的交互 Demo。全部客户、公司、货源、聊天和金额是虚构样例，不代表真实业绩。页面复用项目已实现的匹配、报价和发送前检查逻辑；实时 AI、WhatsApp、正式鉴权与生产数据库仍未接入。

## 直接打开

运行构建后，`artifacts/TradeFlow-demo.html` 是单文件离线版本，用浏览器打开即可展示，无需安装环境、联网或启动数据库。离线版使用系统字体；在线版为私人 Sites 演示站点。

开发预览：

```sh
pnpm install --frozen-lockfile
pnpm build:demo
pnpm dev:demo
```

打开 `http://127.0.0.1:4173`。

## 三分钟演示顺序

1. 打开工作概览。说明首页展示的是当前需要处理的机会和团队任务，而不是只有聊天窗口。六位模拟客户有负责人，内部与供应商库存各有来源。
2. 点击“演示完整业务流程”。Omar 的 200 台 iPhone 13 需求已有产品、版本、数量、目标价和交付地记录。两个有效货源可比较；Supplier C 虽然便宜，却因过期被排除。
3. 点击“采购核验货源”，以王磊的采购角色演示确认数量和底价。随后点击“生成报价草稿”，看到 USD 285 / 台、总金额 USD 57,000。报价截止时间受核验限制，不会简单套用 48 小时。
4. 点击“确认并模拟发送”，再点击“模拟客户确认购买”。会话转给林悦，AI 停止对外回复，锁货和付款交给人工。操作记录可回看每个角色的决策。
5. 到“货源与库存”点击“模拟新货源到货”。Galaxy A25 到货自动找回 Daniel 之前未成交的 150 台需求。强调价值在于需求没有随当时的“无货”而消失。

## 可选风险演示

在报价草稿页点击“模拟核验过期”，再点击“验证过期发送拦截”。页面会明确阻止发送；返回询单重新核验后生成新报价，旧报价被替代。

客户报价可打印，打印版隐藏内部底价与利润依据。各数据页可以导出模拟 CSV。搜索支持客户、型号和货源筛选。

## 每次展示前

左侧“演示说明”→“重置模拟数据”→“确认重置”。这是浏览器本地模拟进度，刷新会保留，重置不会触碰项目数据库。演示业务时间固定为 2026-10-08 15:30，以便反复展示有效期场景。

## 实现边界

Demo 采用浏览器本地状态，角色切换是预设演示，不是生产权限认证。对话是预设样例，采购核验由演示按钮触发，发送仅改变本地状态。在线版保持私人访问；离线文件可由本人现场展示，文件内只有模拟数据。

开发源文件在 `apps/web/demo`，打包脚本在 `scripts/build-demo.mjs`。Sites 的独立发布仓库在 `sites/trade-demo`，主项目忽略该目录以避免嵌套 Git 仓库。部署产物中的 `domain.js` 由现有 TypeScript 业务模块生成，不重复维护价格规则。

演示报价策略：采购成本 278 美元，内部底价 282 美元，客户目标价与建议报价 285 美元。点击生成报价后，销售可调整最终价格；低于内部底价会被拦截。此策略待业务方确认。已有演示报价保留原价格，重新核验并生成新报价即可体验新流程。

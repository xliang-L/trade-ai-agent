## 第一版范围

以第十七节分阶段表和 MVP 具体清单为准：团队共享 CRM、供应商、内部库存、外部货源、历史询单、WhatsApp 接待、基础知识库、匹配、人工核验工作台、报价利润规则、48 小时有效期、基础审批、接管与审计。

## 文档内部范围差异

- 第十七点一概述写“基础社媒发布”，但分阶段表将生成与发布放到第二阶段。建议第一版仅预留渠道和内容结构，不承诺实际社媒发布。
- MVP 清单要求人工审批，第二阶段又列“报价审批”。第一版做必要的底线和特殊报价审批，第二版扩展配置化审批流程。
- 第二十一节混合三阶段验收。老客户主动触达与社媒发布应属于第二版验收，不能据此扩大第一版。
- 文档默认报价有效期为 48 小时；实际报价截止时间还须受货源和核验有效期约束，不能比其更晚。

## 初始假设

同一公司多业务员共享货源与知识库，客户按负责人和团队授权访问；暂不假设客户资料全员可见。系统保留组织边界，不在第一版建设复杂 SaaS 计费与多租户运营平台。

WhatsApp 接入方式、现有表格结构、ERP、主要语言、报价规则和核验有效期尚未给定。初期可用模拟渠道与人工辅助模式验证流程，真实上线须完成账号与 API 能力验证。本文提出的技术方案属于设计建议，不冒充需求原文。
